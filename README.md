## About

I'm an Agentic AI Engineer at **Hilton Worldwide**, where I architected the **Hilton QE Agent** — a production multi-agent system on **Amazon Bedrock (Claude Opus 4.6)** using LangChain and CrewAI that automates Test Scenario generation and cut manual QE effort by **70%**. I also engineered an Agentic RAG pipeline integrating Splunk and Confluence that reduced Mean Time to Resolution by **50%**.

Previously, I built the *Health Assistant* chatbot at **HealthKard** using LangChain with GPT-4o and Claude, and led production ML at **Capgemini**, where I shipped an XGBoost fraud-detection pipeline (88% accuracy, 0.94 AUC) processing 10K+ daily claims and an end-to-end MLOps platform on Amazon EKS.

I hold an M.S. in Computer Science from the **University of Dayton** and care about three things: agent autonomy without losing trust, retrieval quality you can measure, and infrastructure that doesn't wake you up at 3 AM.

## Current Focus

- **Agentic systems** — Multi-agent orchestration with LangChain, LangGraph, CrewAI, and the Model Context Protocol (MCP); planner/executor patterns with tool use and function calling.
- **Advanced RAG** — GraphRAG and Agentic RAG with hybrid retrieval, semantic chunking, and rigorous evaluation via RAGAS and TruLens (consistently shipping sub-5% hallucination rates).
- **LLM fine-tuning** — LoRA, QLoRA, and PEFT on domain-specific synthetic data; instruction tuning and guardrail design.
- **Production MLOps** — AWS SageMaker/Bedrock/EKS/Lambda, Terraform IaC, MLflow, vLLM, and Ollama for self-hosted inference.

## Featured Projects

### QDev Orchestration — Agentic SDLC Platform with Human-in-the-Loop Gates
*Production agentic platform for end-to-end software delivery* · **[Live Demo](https://qd-orchestrationai.vercel.app/)**

An end-to-end SDLC orchestration platform that drives a user story through **Dev → QE → Test → Stage → Prod** via 6 specialized Claude agents (Manager, Dev, QE, Code Review, Splunk → Bug), gated by 3 human-in-the-loop checkpoints, with a state-machine bug-fix loop that retries failed runs using prior failure context.

- **Stack:** Claude Sonnet 4.6 / Opus 4.7, FastAPI, React/Vite/Tailwind, Monaco Editor, WebSockets, Vercel + Render
- **Highlights:** Hybrid model routing with per-agent token accounting · 8+ integrations (Jira, GitHub, Jenkins, Splunk, Docker, Anthropic) with 30 s health polling · sub-second live state streaming over WebSockets

### Advanced Agentic RAG Pipeline for SEC Filings
*Production RAG over SEC 10-K / 10-Q filings* · **[Live Demo](https://advanced-rag-pipeline-app-rohit.streamlit.app)**

A production Agentic RAG application using LlamaIndex, Groq Llama-3.1-70B, and planner-executor agents, with hybrid retrieval (dense all-MiniLM-L6-v2 + sparse BM25 fused via Reciprocal Rank Fusion, k=60) and RAGAS-based evaluation.

- **Stack:** Python, LlamaIndex, ChromaDB, Groq, Streamlit, RAGAS
- **Highlights:** **95%** context precision · **<5%** hallucination rate · **23%** retrieval lift over dense-only baseline · interactive Streamlit dashboard with latency metrics and retrieval comparison

### Face-Generation-Diffusion

A custom diffusion model trained on 100K+ images, optimized with mixed-precision training and gradient checkpointing.
